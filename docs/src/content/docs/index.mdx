## How It's Made

Chronicle transforms raw combat log text into structured, queryable raid data. This wiki documents the systems that make it work.

<CardGrid stagger>
	<Card title="Combat Log Parsing" icon="document">
		Vanilla WoW logs are human readable strings. Chronicle uses a regex based parser to handle the chaos.
	</Card>
	<Card title="Encounter Detection" icon="seti:config">
		No `ENCOUNTER_START` events in vanilla. Chronicle infers boss fights from damage patterns, deaths, and activity periods.
	</Card>
	<Card title="Period Tracking" icon="pulse">
		Active vs Inactive states, inactivity timeouts, reset grace periods — how Chronicle knows when a fight starts and ends.
	</Card>
	<Card title="Instance Recognition" icon="star">
		Zone detection, boss identification, and the identity system that classifies every entity in the log.
	</Card>
</CardGrid>
